## cefore-emu 0.2.0 — 再現・検証・共有できる ICN 障害実験基盤

第33回 ICN 研究会（2026-08）ポスター発表時点のスナップショット。

- **YAML 一枚で実験を定義**: `linear` / `mesh` / `disaster` / `connect` の 4 トポロジを統一 CLI（`ceforeemu`）から起動し、Mininet 上で cefnetd を並べて put/get・pub/sub・ホスト断・リンク断・帯域制御を再現する。
- **検証を結果に埋め込む**: イベントごとの outcome（`ok` / `not-ok` / `skipped-no-result`）と ccninfo 経路・キャッシュトレース、monitor.json を実験ログとして残し、`ceforeemu-log` で要約する。
- **共有できる**: `uv sync` だけで依存が揃い、PR と main への push は GitHub Actions で pytest（coverage 85% 床）/ ruff / mypy / lockfile / entry-points 検査を通過したものだけが入る（ADR-0004）。

既知の Cefore 0.12.0 上流挙動（CS_MODE=2 発信元からの ccninfo 応答など）と回避策は CONTEXT.md を参照。wheel / PyPI 配布は本リリースの対象外。
