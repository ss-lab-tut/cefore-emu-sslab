# PLAN.md

Freeform scratch space for a coding agent to jot in-progress implementation
plans while working on a task: task breakdowns, options under
consideration, open questions, slice/step sequencing.

This file is not durable documentation and is expected to be overwritten
at the start of each new task. Once a plan is finished or a decision is
made, move anything worth keeping into:

- `CONTEXT.md` — project glossary and domain language
- `CLAUDE.md` — development conventions and guidance
- `docs/adr/` — architecture decision records

See CLAUDE.md for the full role distinction between this file and durable docs.
